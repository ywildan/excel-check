Tolong buatkan sistem Audit Excel untuk tugas Pengantar Akuntansi, lengkap dari plugin mahasiswa sampai alat checker dosen. Saya mahasiswa D4 Akuntansi Perpajakan. Baca semua syarat di bawah sampai habis sebelum mulai. Jangan tanya lagi, langsung kerjakan.

====================
1. KONTEKS MASALAH
====================
Di matkul Pengantar Akuntansi, setiap tugas kami diminta membuat Jurnal Umum sampai Neraca Saldo / Laporan Keuangan. Dosen melarang memakai Excel (harus manual di buku) karena takut mahasiswa menyalin kerja teman dengan cepat atau memakai AI.

Saya ingin membuktikan Excel tetap bisa dipakai secara jujur, dengan bukti pengerjaan yang bisa diperiksa dosen. Jadi sistem ini harus mencatat BUKTI pengerjaan, bukan cuma isi jawabannya.

====================
2. TUJUAN AKHIR
====================
Buatkan 2 bagian yang saling berkaitan dan memakai format data yang SAMA:

A. PLUGIN / TEMPLATE EXCEL UNTUK MAHASISWA
B. ALAT CHECKER UNTUK DOSEN (web lebih diutamakan, atau .exe)

====================
3. SYARAT PALING PENTING: SETUP AKHIR TIDAK BOLEH RIBET
====================
Ini syarat mutlak. Kalau setup-nya ribet, sistem ini gagal meskipun kodenya bagus.

Untuk MAHASISWA, cara pakai akhirnya maksimal 3 langkah:
  1. Download 1 file.
  2. Buka file itu, klik Enable Content kalau muncul.
  3. Isi identitas, tekan MULAI, kerjakan, tekan SELESAI & KUNCI.
Selesai. Tidak boleh ada langkah lain.

Untuk DOSEN, cara pakai akhirnya maksimal 3 langkah:
  1. Buka 1 link web (atau buka 1 file .exe).
  2. Upload / drag-drop file .xlsm tugas mahasiswa.
  3. Lihat hasil penilaian di dashboard.
Selesai.

DILARANG di hasil akhir:
- Dilarang menyuruh mahasiswa buka Alt+F11.
- Dilarang menyuruh mahasiswa Import file .bas / .frm manual.
- Dilarang menyuruh mahasiswa pakai Custom UI Editor, edit registry, edit file zip, atau ubah [Content_Types].xml manual.
- Dilarang menyuruh mahasiswa atau dosen install Python, pip install openpyxl, install Node, atau jalankan perintah terminal.
- Dilarang menyuruh dosen install Python / jalankan script .py manual. Checker harus sudah jadi web atau .exe siap pakai.
- Dilarang menyerahkan file .bas terpisah sebagai "cara instalasi". File .bas hanya boleh ada sebagai source code di folder source, BUKAN sebagai langkah instalasi.

File .xlsm final yang diserahkan HARUS sudah berisi VBA/macro di dalamnya dan sudah teruji bisa dibuka langsung. Kalau kamu tidak bisa membuat .xlsm bermacro yang valid di environment kamu, JANGAN serahkan .bas sebagai gantinya. Pilih jalur VSTO di bawah ini sebagai gantinya:
  Jalur yang diterima:
  a. .xlsm dengan VBA sudah ter-embed dan teruji dibuka di Excel Windows, ATAU
  b. Satu installer .msi / .exe yang sekali klik langsung memasang add-in + template tugas ke Excel, tanpa langkah manual lain.

Pilih salah satu jalur di atas, dan tulis di README jalur mana yang kamu pilih dan kenapa. Jangan serahkan dua-duanya setengah-setengah.

====================
4. SPESIFIKASI PLUGIN MAHASISWA
====================
Target: Excel Desktop Windows saja. Tidak perlu Excel Online / Mac / HP.

Sheet yang harus ada di template:
- Petunjuk (cara pakai singkat, Bahasa Indonesia)
- Identitas
- Jurnal Umum (template 35 baris, kolom No, Tanggal, Keterangan/Akun, Ref, Debit, Kredit, Total Debit =SUM, Total Kredit =SUM, Selisih = Debit-Kredit harus 0)
- Neraca Saldo (kolom No, Nama Akun, Debit, Kredit, Total)
- Dashboard Audit (terlihat oleh mahasiswa)
- _AUDIT_LOG (veryHidden, jangan terlihat di tab sheet biasa)

Form identitas (di sheet Identitas, bukan UserForm yang rapuh):
- Nama, NIM, Kelas, Mata Kuliah, Judul Tugas
- Semua wajib diisi sebelum tombol MULAI bisa ditekan.
- Setelah SELESAI & KUNCI, Identitas dan Jurnal terkunci dan tidak bisa diubah lagi.

Tombol / menu (harus sudah ada di file final, tidak perlu dipasang manual):
- MULAI
- JEDA / LANJUT
- SELESAI & KUNCI
- LIHAT LOG (opsional, hanya untuk melihat, bukan mengedit)
Tombol boleh berupa Ribbon "Tugas Akuntansi" ATAU tombol di sheet Dashboard. Pilih yang paling simpel dan sudah teruji jalan. Jangan pakai Ribbon kalau Ribbon-nya belum teruji.

TIMER AKTIF — INI FITUR INTI, HARUS AKURAT:
- Timer dicek tiap 1 detik.
- Gunakan GetLastInputInfo() di Windows (waktu terakhir mouse ATAU keyboard dipakai di seluruh Windows, bukan cuma di Excel).
- Jika diam lebih dari 5 detik (5000 ms), timer JEDA: Waktu Aktif TIDAK bertambah, hanya Waktu Diam yang bertambah.
- Jika mouse/keyboard bergerak lagi, timer jalan lagi otomatis.
- Jika Excel bukan window yang sedang aktif (misal user pindah ke browser/Word), hitung sebagai DIAM juga.
- Jangan cuma lacak mouse. Mahasiswa yang sedang mengetik angka tanpa menggerakkan mouse harus tetap dihitung AKTIF.
- Jangan pakai Total Editing Time bawaan Excel. Fitur itu di Excel tidak jalan / tidak bisa diandalkan.

Data yang HARUS dicatat plugin:
- active_seconds (detik benar-benar aktif)
- idle_seconds (detik diam)
- edit_count (jumlah perubahan sel di Jurnal/Neraca, bukan di Dashboard/Log)
- paste_count (perubahan >1 sel sekaligus, atau saat CutCopyMode aktif)
- save_count (berapa kali Save)
- formula_count (sel rumus) dan value_count (sel angka/teks yang diketik)
- session_start dan session_end setiap kali file dibuka-ditutup
- Log event dengan waktu: MULAI, JEDA, LANJUT, PASTE, SIMPAN, SELESAI, TUTUP

Tempat menyimpan log (supaya checker dosen bisa baca tanpa Excel):
- Simpan di sheet _AUDIT_LOG (veryHidden) DAN di CustomDocumentProperties dengan nama Audit_NIM, Audit_Nama, Audit_ActiveSeconds, Audit_IdleSeconds, Audit_EditCount, Audit_PasteCount, Audit_LastHash, Audit_Finished.
- Angka harus tetap tersimpan kalau file ditutup lalu dibuka lagi (tutup-buka tidak boleh mereset ke 0).
- Beri hash rantai sederhana pada log (hash baris sebelumnya + isi baru), supaya kalau log diedit manual, checker bisa mendeteksinya. Tulis jelas di README bahwa hash ini BUKAN tanda tangan digital resmi.

Dashboard Audit harus menampilkan (Bahasa Indonesia):
- Status: BELUM DIMULAI / AKTIF / IDLE — timer jeda (>5 detik diam) / DIJEDA / SELESAI & TERKUNCI
- Waktu Aktif (jam menit detik + detik)
- Waktu Diam (jam menit detik + detik)
- Jumlah Edit, Jumlah Paste, Jumlah Save
- Hash log terakhir

====================
5. SPESIFIKASI CHECKER DOSEN
====================
Dosen menerima file .xlsm dari mahasiswa, lalu upload ke alat ini. Alat harus otomatis membedah file itu tanpa membuka Excel.

Yang harus dibaca alat:
1. CustomDocumentProperties Audit_* dan sheet _AUDIT_LOG.
2. Metadata standar Excel: Author, Last Modified By, Created, Modified.
3. Isi Jurnal Umum: jumlah baris terisi, Total Debit/Kredit, hash isi Jurnal.

Yang harus ditampilkan alat (dashboard per mahasiswa):
- Nama, NIM, Kelas, Judul Tugas (dari form identitas)
- Waktu Aktif dan Waktu Diam
- Edit, Paste, Save
- Status log: ADA / HILANG / DIMANIPULASI (hash tidak cocok)
- Cross-check: NIM di form vs Author Excel. Kalau berbeda, beri flag.
- Penilaian otomatis berupa flag, BUKAN vonis. Contoh flag:
  * NORMAL
  * CURIGA: aktif <10 menit tapi edit banyak / isi lengkap
  * CURIGA: paste mendominasi (misal 1x paste ratusan sel)
  * CURIGA: file disalin (Author sama dengan mahasiswa lain)
  * LOG HILANG / TIDAK ADA Audit_* (file tidak dikerjakan pakai plugin)

Fitur tambahan yang wajib ada di checker:
- Bisa upload BANYAK file sekaligus (satu kelas).
- Bandingkan hash isi Jurnal antar file. Kalau dua file isinya sama persis, tandai sebagai kemungkinan salinan dan tampilkan pasangan namanya.
- Tampilkan ringkasan kelas: berapa NORMAL, berapa CURIGA.

====================
8. CARA VERIFIKASI SEBELUM MENYERAHKAN (WAJIB DILAKUKAN AGENT)
====================
Sebelum menyerahkan, agent WAJIB menguji sendiri dan melaporkan hasilnya. Jangan klaim sudah dites kalau belum.

Uji mahasiswa:
1. Buka file final dari kondisi bersih (seolah-olah mahasiswa baru download). Isi identitas, tekan MULAI.
2. Gerakkan mouse / ketik selama 30 detik. Waktu Aktif harus naik sekitar 30 detik.
3. Diam total 20 detik tanpa menyentuh mouse/keyboard. Waktu Aktif TIDAK BOLEH bertambah. Hanya Waktu Diam yang naik.
4. Tutup file, buka lagi. Angka Waktu Aktif, Edit, dan Log TIDAK BOLEH hilang / reset ke 0.
5. Tekan SELESAI & KUNCI. Pastikan Identitas dan Jurnal terkunci, dan file tersimpan.

Uji dosen:
6. Upload file hasil uji di atas ke checker. Checker harus menampilkan Nama/NIM, Waktu Aktif yang benar, dan status NORMAL.
7. Uji file kosong / file tanpa plugin: checker harus menampilkan flag LOG HILANG / TIDAK ADA Audit_*, bukan crash.
8. Uji 2 file dengan isi Jurnal yang sama persis: checker harus menandai kemungkinan salinan.

Kalau ada satu saja uji di atas yang gagal, perbaiki dulu, jangan serahkan dengan alasan "seharusnya jalan". Tulis hasil tiap uji (LOLOS / GAGAL + angka yang terlihat) di laporan pengujian.
